# 设计令牌提取

用于从 Figma 设计系统提取变量、颜色、字体、间距等设计令牌，并生成 JSON 与 QML 单例。先完整读取[原始说明](原始说明.txt)。

- 使用已有且已授权的 Figma 连接，或用户提供的本地导出资料；缺少来源时如实说明需要的数据，不在聊天中索取密钥。
- 读取[令牌映射](references/token-mapping.md)，按原流程处理引用、模式和语义层级。
- `examples/` 内保留原有 QML 单例示例。结合实际设计结构调整，不把示例内容当作用户设计数据。
- 组件生成需要令牌和相应单例；完成后按任务转到兄弟目录的组件生成模块。已有合适的令牌时不重复提取。

示例和相对路径以本目录为基准，不擅自写回 Figma。
