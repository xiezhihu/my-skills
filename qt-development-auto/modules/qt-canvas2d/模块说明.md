# 二维画布

用于 Qt Canvas2D 的 GPU 二维绘图与迁移。先完整读取[原始说明](原始说明.txt)，再按流程读取[规则](references/rules.md)及[接口参考](references/api-reference.md)。

- 检查实际 Qt 版本，Canvas2D 面向 Qt 6.12 及以上。不要把旧 Qt Quick Canvas 或 HTML5 Canvas 的 API 直接套入。
- 移植旧画布时读取[迁移说明](references/porting.md)。
- 按绘图内容选择 `references/recipes/` 中的对应示例；只加载相关示例，再结合实际数据和交互调整。
- 渲染器尚未确定时比较合适的实现。任务已要求保留旧 Canvas，或已有 Shape/ShapePath 实现且不涉及迁移时，不强行替换。

所有示例和相对路径以本目录为基准。
