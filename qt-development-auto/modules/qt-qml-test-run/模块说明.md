# 运行 QML 测试

用于 Qt 6、CMake 项目的本机 Qt Quick Test 构建、运行和报告。先完整读取[原始说明](原始说明.txt)。

- 查找已有测试及 Qt 工具。没有测试时报告现状；写测试属于兄弟目录中的生成 QML 测试模块。
- 未有 CMake 测试接线时，按原始流程优先考虑直接使用 `qmltestrunner`。不默认修改根工程或新增测试入口。
- 用户要求接线时读取[构建集成](references/qt-quick-test-cmake.md)，在已有授权内完成对应改动。
- 结果解析脚本为 `references/scripts/parse-qmltestrunner-output.py`，报告规则见[测试报告格式](references/qt-quick-test-report-format.md)。
- 区分未能启动、构建失败、用例失败、跳过和全部通过。该流程不代表支持跨设备执行、qmake、C++ QtTest 或 Squish。

脚本和相对路径以本目录为基准。
