# 生成 QML 测试

用于生成 Qt Quick Test 的 TestCase、SignalSpy、异步属性和交互测试。先完整读取[原始说明](原始说明.txt)，按其流程读取相关参考。

- 先读取[项目上下文](references/qt-quick-test-project-context.md)和[测试规则](references/qt-quick-test-rules.md)，以实际组件接口和用户行为设计测试。
- 依需要选择[属性测试](references/qt-quick-test-properties.md)、[控件测试](references/qt-quick-test-controls.md)与[源码导入](references/qt-quick-test-source-import.md)。
- 使用[模板](references/qt-quick-test-template.md)时结合真实组件调整，完成前参考[常见陷阱](references/qt-quick-test-pitfalls.md)及[交付前检查](references/qt-quick-test-pre-send-scan.md)。
- 需要执行测试时转到兄弟目录的运行 QML 测试模块；仅生成文件不能宣称测试已通过。

所有相对路径以本目录为基准。
