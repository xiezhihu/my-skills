# 生图提示词整理规范

本文件复用系统 `$imagegen` Skill 中与提示词整理相关的通用规范，不调用 `$imagegen` 先生成图片。

## 整理原则

- 先理解用户意图，再补充对画面有实际帮助的细节。
- 用户已经给出详细要求时，只做结构化整理，不擅自扩展主题。
- 用户需求较笼统时，可以适度补充构图、画面层次、光线和成品用途。
- 不凭空加入品牌、口号、人物身份、故事情节或无关物体。
- 图片中的文字必须逐字保留，并要求准确、清晰、完整呈现。
- 编辑任务必须明确“只改变指定内容，其他主体、姿势、服装、比例、边缘和构图保持不变”。

## 推荐结构

根据任务选择相关字段，不需要机械填满：

```text
用途：广告宣传、产品图、概念图、头像、社交媒体配图等
素材类型：照片、插画、三维渲染、海报等
主要请求：用户要生成或修改的内容
场景/背景：环境、地点、时间和背景元素
主体：主要人物、物体或视觉焦点
风格/媒介：写实、电影感、商业插画、手绘等
构图/取景：横竖版、景别、视角、主体位置和留白
光线/氛围：光源、时间、情绪和整体气氛
色彩：主色、辅助色和对比关系
材质/纹理：表面质感、细节和真实感
文字（原文）：必须准确呈现的图片文字
约束：必须包含或必须保持的内容
避免：乱码、水印、Logo、畸形、无关元素等
```

## 调用前检查

- 文生图使用 `generations` 接口；编辑任务使用 `edits` 接口。
- 参考图和蒙版要区分角色，不能把蒙版当作普通参考图。
- 文字要求放入“文字（原文）”，不要只依赖自然语言描述。
- 只把整理后的最终提示词发送一次给图片供应商，不先调用 `$imagegen` 生成中间图片。
