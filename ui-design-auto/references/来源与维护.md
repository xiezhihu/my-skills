# 来源与维护

## 来源

本技能根据此前安装的十九个桌面界面设计技能进行了中文整合与重写，保留场景、布局和关键交互的覆盖范围，并增加自动选择、组合和冲突处理规则。

原项目：

```text
https://github.com/umutc6230/ui-design-skills-pack
```

原项目许可证为 MIT，版权声明为 `Copyright (c) 2026 palamut62`。本技能根目录的 `LICENSE` 原样保留上游许可证文本，正文及十九份方案参考采用简体中文编写。

## 内部结构

- 根目录 `SKILL.md` 是唯一技能入口，负责触发范围、自动选择和一致性规则。
- `agents/openai.yaml` 提供中文显示名称和默认提示，保留自动触发能力。
- `references/styles/` 内有十九份中文方案，编号与原项目一一对应。
- 内部参考不是独立安装的技能，没有各自的技能入口。复制整个文件夹即可携带全部方案，无需依赖原来的十九个技能目录。

## 维护方式

原来的十九个独立技能已从共享技能库移除。本技能内置全部十九份中文方案，可以独立使用；后续通过原项目仓库追溯上游变化。中文整合内容需按需维护，不会自动随上游更新。

更新时，先对照上游变化，修改对应的中文方案；若新增或移除方案，同时更新根入口的目录和选择规则。不要把十九份内容拼到入口中，也不要在未选择场景前要求读取所有文件。

## 选择检查

维护选择规则后，用实际需求检查以下分界；这些是检查样例，不是已经执行的测试结论。

| 需求 | 应重点检查的判断 |
|---|---|
| 沿用现有红白主题，为库存页增加批量操作 | 保留原主题，只借用数据表格交互 |
| 清晰简洁的多模块客户后台 | 极简侧边栏为主，按需补充数据表格 |
| Windows 原生外观的文档生成助手 | 原生风格为主，聊天与工具面板补充 |
| 实时预览笔记，不需要终端 | 选择分栏，避免强加综合工作台 |
| 有项目树、多编辑标签和日志面板的开发工具 | 区分综合工作台与单纯分栏 |
| 连接地址、密钥和模型配置页 | 设置中心，测试与保存各有真实状态 |
| 普通安全告警管理后台 | 不因安全行业词自动采用赛博朋克 |
| 明确要求复刻旧式 Windows 对话框 | 经典窗体，不混入现代毛玻璃 |
| 截图后迅速识别与复制文字的小工具 | 悬浮工具，不加入完整仪表盘 |
| 修复后端导出接口，不涉及页面 | 不启用界面设计流程 |
