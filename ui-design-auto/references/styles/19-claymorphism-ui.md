# 黏土拟态界面

## 适用与边界

适合偏好可爱、柔软触感的个人助手、创意和轻量教育工具。高密度管理界面若需这种气质，仅局部借用材质与色彩。

## 布局与视觉

- 粉彩表面结合克制的内外阴影，营造柔软体积，而不是把每层容器都包成气泡。
- 可参考粉色 `#FCE7F3`、浅蓝 `#DBEAFE`、薄荷绿 `#DCFCE7`，正文使用深色 `#334155`。
- 圆角按项目设计系统和当前限制确定。大圆角不是硬性要求，不能挤占表单和文字空间。
- 滑杆、开关、进度和少量重复事项可表现轻微触感，长列表与密集表单保持清楚边界。
- 使用支持中文的友好界面字体；短标题和正文仍有明确层次。

## 关键交互

- 悬停和按下用小幅材质变化反馈，不让多重阴影模糊边缘。
- 明确焦点轮廓，粉彩背景上仍能辨认选中、错误与禁用。
- 加载和完成状态语气友好，但不以装饰动画替代进度。
- 长表单适当降低视觉膨胀感，窄窗口优先保留操作空间。

## 验收重点

柔软材质、颜色与阴影方向一致。正文与按钮名称保持足够对比，关闭阴影后仍能辨识控件和完成任务。
