# 悬浮工具窗口

## 适用与边界

适合截图、取色、剪贴板、识别文字和快捷笔记等微型辅助工具。以完成一个短任务为中心，不把完整后台塞进迷你窗口。

## 布局与视觉

- 上方拖动与窗口操作区，中间紧凑控件和结果预览，下方状态或主要动作。
- 初始宽度可参考 `220–360px`，高度按内容约束。外边距参考 `12–16px`。
- 用一个明确的窗口层级与清楚边界即可，不增加多重嵌套卡片。
- 小窗口仍使用可读字号，不能为了塞内容不断缩小正文。
- 开关、模式切换、颜色选择等使用适合的原生或现有控件。

## 关键交互

- 拖动区域与输入、按钮分开；关闭和最小化始终容易找到。
- 置顶由用户控制，明确显示当前状态，必要时记住位置。
- 图标按钮有提示和可访问名称，点击区域按平台与输入方式设定。
- 长结果可展开查看或复制；截断内容能够访问完整文本。
- 完成捕获或复制后显示简短反馈，运行中支持实际可用的取消操作。
- 支持窗口打开、关闭后的焦点返回，不永久遮挡主应用的重要内容。

## 验收重点

小窗口下可以完成主要任务，关闭与恢复方便。移动到不同屏幕或缩放比例后，窗口和主要操作仍在可见范围内。
