# 经典 Windows 窗体

## 适用与边界

仅用于用户明确要求的 Windows 95、98、2000 等复古风格。不要将现代桌面窗体框架自动解释成复古外观。

## 布局与视觉

- 经典标题栏、菜单或工具栏、分组框、标签输入网格、确定取消按钮行与状态栏。
- 可参考窗口底色 `#D4D0C8`、控件表面 `#C0C0C0`、标题栏 `#000080`、文字 `#000000`。
- 圆角参考 `0–2px`，以明暗两侧边框构成内凹输入框和外凸按钮，不使用现代模糊阴影。
- 字体采用可用的系统字体并补充中文回退；复古小字号须经过可读性验证，不能牺牲缩放能力。
- 按钮、选择框、进度条和分组框遵守同一套机械边框规则。

## 关键交互

- 按下按钮时反转边框关系，焦点可使用清晰的点状轮廓。
- 对话框支持回车执行合适的默认动作、退出键取消；危险操作不设为默认聚焦动作。
- 标签、输入与按钮顺序适合键盘操作。
- 反馈简短直接，不加入与复古语言冲突的大幅动效。

## 验收重点

内凹与外凸方向一致，键盘默认行为合理。高缩放下仍能读中文和操作控件，不为复古外观牺牲任务完成能力。
