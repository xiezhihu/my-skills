# 命令面板界面

## 适用与边界

适合启动器、全局搜索和以键盘为主的快速操作。在已有应用中通常作为补充功能，不负责替换主导航或重设整套主题。

## 布局与视觉

- 上方搜索输入，中间分类结果，下方少量上下文信息。
- 桌面面板可参考 `560–760px`，窄屏按可用宽度约束，并限制列表高度。
- 结果行保持图标、标题、简短说明、作用范围和快捷键的顺序，明确区分悬停与当前选择。
- 表面、字体、圆角和强调色继承主方案。快捷键采用等宽显示，不另建一套深色主题。

## 关键交互

- 支持产品约定的打开快捷键、方向键移动、回车执行和退出键关闭。
- 打开后聚焦搜索；关闭后回到原先控件。弹出期间合理管理焦点。
- 查询为空时显示最近使用或常用命令；没有结果时提供清空查询等操作。
- 文件、设置、命令等结果具有明确类型；执行后跳转到真实目标。
- 大量结果采用适当的分段加载或虚拟化，不让查询阻塞输入。
- 删除等不可恢复操作保留与主应用一致的确认或撤销流程。

## 验收重点

仅使用键盘即可打开、筛选、执行和退出。点击与键盘选择行为一致，执行命令后焦点和页面状态合理。
