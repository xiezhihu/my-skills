# 人工智能聊天与工具面板

## 适用与边界

适合以对话发起生成、右侧调整参数并预览或导出结果的助手。没有聊天需求的批处理工具，不为了使用本方案加入聊天框。

## 布局与视觉

- 主区域包含会话标题、消息流和固定在可操作位置的输入区；侧区放与当前任务有关的参数、来源和结果。
- 区分用户、助手、工具运行和结果，但不让每条消息都成为厚重卡片。
- 文字对话、代码、图片与产物预览使用合适的呈现方式。
- 消息正文可参考 `13–16px`，侧栏表单保持紧凑。长回复不会推走输入区。
- 侧栏在窄窗口变为抽屉或独立标签，保持会话和输入可用。

## 关键交互

- 流式生成、工具运行、完成、错误与取消状态清楚；只展示真实可知的运行状态。
- 生成中提供停止，完成后提供与产物对应的复制、打开或导出。
- 回车与换行行为明确，并正确处理中文输入法组合输入。
- 修改模型或格式后，说明作用范围，避免错误暗示会追溯改变历史内容。
- 用户向上阅读时不强制滚回底部，必要时显示新消息入口。
- 错误保留原输入和已产生的内容，允许编辑重试。
- 没有真实服务时明确演示范围，不虚构工具已执行或文件已生成。

## 验收重点

参数能够影响实际请求，预览与导出对应同一产物。长会话、流式输出、取消和重试不破坏输入与滚动位置。
