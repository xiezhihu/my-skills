# Windows 11 风格界面

## 适用与边界

适合用户明确要求 Windows 原生体验的桌面应用。原生感来自导航、命令栏、设置行、菜单和系统字体的整体协作，不只是背景模糊。不要仅因为项目使用某种语言就自动选择此方案。

## 布局与视觉

- 侧边导航、顶部命令栏、主体内容与短任务弹层保持稳定层次。
- 优先使用目标平台现有原生控件及主题资源；网页实现则统一设计变量，不假装调用了系统原生材质。
- 字体可用 `Segoe UI Variable`、`Segoe UI`，中文补充系统中文字体回退。
- 间距参考 `4px` 基础。列表和设置行可参考 `40–48px`，有触摸需求时扩大目标。
- 云母或亚克力材质用于外框和背景层，密集表格与表单保持不透明。

## 关键交互

- 主要命令靠近页面标题，次要动作放到工具栏尾部或更多菜单。
- 导航选中、控件悬停和键盘焦点清楚分离。
- 弹出菜单和对话框聚焦短任务，关闭后恢复原上下文。
- 支持文本缩放、高对比与窄窗口布局，避免固定像素导致裁切。
- 原生窗口的拖动、最大化和系统按钮遵守平台约定。

## 验收重点

关闭材质效果后仍有一致的原生布局。键盘、文字放大与高对比状态都能完整完成主要工作流。
