# 卡片式仪表盘

## 适用与边界

适合快速回答当前状况、变化趋势和待处理异常的统计界面。指标和图表需要独立呈现时才使用卡片，不把每个页面章节都包成卡片。

## 布局与视觉

- 页面范围与筛选在上，核心指标优先，主图表居中，次要分析和明细在后。
- 重要指标在较小桌面窗口的首屏仍可见；根据数量调整网格，不固定所有产品都使用四列。
- 指标统一展示名称、主值、统计周期、比较基准和变化方向。
- 中性背景搭配少量强调色，成功、警告与错误另有明确含义。相同数据在不同图中使用一致颜色。
- 数字格式、单位、小数位和日期范围统一。卡片内文字层级紧凑，避免主值挤压其他内容。

## 关键交互

- 区分全局筛选和局部筛选，活动条件可见且可清除。
- 指标或图表可下钻到对应明细，返回后保留查询状态。
- 按模块加载、重试和展示错误；不要因一个数据源失败清空整个页面。
- 告警包含严重程度、发生时间和可执行操作，不能只当彩色装饰。
- 没有任何数据与筛选无结果使用不同空状态。

## 验收重点

无需逐个打开模块就能看到主要结论。改变时间范围后指标、趋势和明细同步，图表不能只展示没有含义的装饰曲线。
