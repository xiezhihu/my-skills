# 赛博朋克抬头显示界面

## 适用与边界

适合明确要求科幻、霓虹或游戏控制台主题的界面。安全监控、遥测等行业词本身不足以触发此风格；普通工作界面优先清晰稳定。

## 布局与视觉

- 依真实功能组织系统状态、遥测数据、目标或模式设置、事件日志与控制操作。
- 可参考黑色背景、青色 `#22D3EE` 强调、警告 `#FACC15` 和告警 `#F43F5E`。
- 使用锐利边框或有限的切角，发光仅帮助区分层级，不让正文发糊。
- 技术字体用于短标签与数据；中文与长文本仍选可读字体，不采用全篇装饰字。
- 装饰扫描线和动态纹理默认从简，不妨碍查看数据。

## 关键交互

- 普通、运行、警告与告警结合文字和图标区分，不让红色同时承担装饰用途。
- 键盘焦点使用清楚轮廓，不依靠动态发光。
- 动态效果遵守减少动画的系统偏好，避免持续闪烁和抢眼扫描。
- 启动、执行、中止与结果区分明确；高影响操作遵守产品的确认或撤销机制。

## 验收重点

关闭发光和动画后仍能完整操作。主题感不会掩盖数据层级、告警含义和主要动作。
