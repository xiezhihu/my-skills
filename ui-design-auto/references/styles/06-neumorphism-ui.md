# 新拟态界面

## 适用与边界

适合明确需要柔和浮雕和按压触感的个人工具、媒体控制或轻量设置。密集业务表格和依赖高辨识度的工作界面不默认使用此方案。

## 布局与视觉

- 使用同一浅色表面的亮暗双阴影区分凸起与凹陷，保持光源方向一致。
- 可参考背景 `#EEF2F7`、暗阴影 `#B9C7D9`、亮部 `#FFFFFF`、正文 `#1F2937`。
- 浮雕主要用于按钮、开关、滑杆和分段控件，不给每一层容器都加双阴影。
- 表单与长列表提高边界清晰度，必要时回到普通不透明表面。
- 圆角和尺寸遵守主设计变量；柔和触感不依赖无限增大的圆角。

## 关键交互

- 按下状态可以改用内阴影，同时以颜色、图标或位置表达，不能只翻转阴影。
- 输入、聚焦、选中与禁用具有明确差别，焦点使用清晰轮廓。
- 错误、成功和警告使用可读的图标与文字，不被柔和材质掩盖。
- 深色主题需要重新设计亮暗关系，不直接反转浅色阴影。

## 验收重点

关闭阴影或启用高对比模式时仍能识别交互控件。小窗口中不能因大面积浮雕和留白使主要操作不可见。
