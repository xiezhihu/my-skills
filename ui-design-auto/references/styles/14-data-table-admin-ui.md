# 数据表格管理界面

## 适用与边界

适合用户、库存、客户、文件与订阅等大量记录的操作管理。与统计仪表盘不同，表格是主要工作对象；概览指标仅按需要补充。

## 布局与视觉

- 工具栏提供标题、搜索和主操作；筛选区展示活动条件；表格后提供数量和分页；详情按需使用抽屉。
- 主字段比元数据更突出，数值列对齐并统一单位，长文本可展开查看。
- 行高可参考 `40–52px`，但按平台、缩放与触摸需求调整。表头、悬停、选中和焦点应可分辨。
- 列宽按数据类型设计，不平均分配所有列；必要时固定主列或操作列。
- 状态采用文字与图标，不能只靠红绿颜色。

## 关键交互

- 列标题支持真实排序并显示方向；搜索、筛选、分页与排序共同作用于一致的数据集。
- 多选后显示选中数量与批量操作；明确“选择当前页”还是“全部匹配记录”。
- 改变查询或页码后合理处理选中状态，不对看不见的旧记录误操作。
- 区分加载、无记录、筛选无结果和加载失败；失败时保留上下文并提供重试。
- 窄窗口采用受控的横向滚动或明确的信息重排，不用裁切隐藏关键操作。
- 详情返回后保留查询与位置；删除和批量修改反馈实际结果。

## 验收重点

完整走通筛选、排序、选择、批量操作和详情返回。记录数量、页数与选择范围准确，加载时布局稳定。
