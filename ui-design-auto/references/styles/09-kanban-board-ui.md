# 看板界面

## 适用与边界

适合任务按状态流转、项目阶段管理和计划安排。需要密集比较多列属性时优先提供列表或表格视图，不把所有记录都强行变成拖拽卡片。

## 布局与视觉

- 上方项目标题与筛选，下方按阶段排列的列，点击任务进入详情抽屉或页面。
- 列标题显示名称、数量和确有需要的进行中数量限制。
- 卡片按固定顺序呈现标题、关键标签、负责人、日期和优先级，避免填满所有元数据。
- 列宽可参考 `280–320px`，看板整体允许横向滚动，列内任务列表合理纵向滚动。
- 色彩表示状态、标签或优先级，文字和图标共同说明含义。

## 关键交互

- 拖动前可识别拖动区域；卡内有其他按钮时使用独立拖动手柄。
- 拖动中显示目标列与插入位置，移动完成后反馈结果。
- 提供“移至某列”“上移”“下移”等非拖拽操作，支持键盘用户。
- 添加任务、筛选和查看详情都能回到原先看板位置。
- 支持多选时显示选择数量与适用操作；不实现仅有外观的批量拖动。
- 存储失败时回退或说明未同步状态，不悄悄丢失任务。

## 验收重点

鼠标和键盘都能改变任务状态。空列可添加任务，长标题不会撑坏卡片，横向滚动不会带走顶部筛选。
