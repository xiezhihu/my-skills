# 极简侧边栏界面

## 适用与边界

适合多模块业务应用、日常记录、列表和表单。重点是稳定导航和顺畅操作，而不是装饰。大批量记录管理可补充数据表格方案。

## 布局与视觉

- 左侧导航、顶部页面标题与操作区、主体列表或表单；确需同时查看详情时再加入右侧详情。
- 桌面侧边栏可参考 `220–260px`，主要模块较多时用分组，次级页面通过标签或面包屑组织。
- 使用中性浅背景、不透明内容表面和细分隔线。可参考背景 `#F6F8FB`、表面 `#FFFFFF`、文字 `#111827`。
- 强调色用于主操作和当前导航。选中状态同时体现图标、文字或表面变化。
- 正文参考 `14–16px`，列表行高参考 `44–52px`；字号不随视口宽度缩放。

## 关键交互

- 列表、详情、编辑和返回路径一致；保存、取消放在稳定位置。
- 搜索与筛选保持当前状态，清空条件能够恢复完整列表。
- 侧边栏折叠成图标后保留名称提示与可访问名称。
- 空数据区提供与当前任务相关的操作，例如新增记录或清除筛选。
- 导航与内容各自合理滚动，长菜单不使整个界面持续位移。

## 验收重点

用户能快速理解所在位置、主要动作和返回路径。窄窗口下导航可以收起，列表或表单不被挤压，长标题不会遮挡操作。
