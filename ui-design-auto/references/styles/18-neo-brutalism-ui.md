# 新粗野主义界面

## 适用与边界

适合明确偏好粗边框、硬阴影与大胆色块的创作或任务工具。密集业务表格不默认整屏采用这种强表现力外观。

## 布局与视觉

- 大标题与主要动作清楚，内容按实际工作流排列，重复事项才采用卡片。
- 参考黑色文字和边框、白色表面，配少量黄色 `#FEF08A`、粉色 `#F9A8D4`、绿色 `#86EFAC` 等色块。
- 边框可参考 `2–3px`，硬阴影可参考 `3–6px` 偏移，方向始终一致。
- 圆角偏小或为零，避免同时混入毛玻璃、柔和浮雕和模糊阴影。
- 字重有力度但层次分明；小标签不一律大写，中文保持正常可读排版。

## 关键交互

- 按下时轻微移动并减小硬阴影，固定占位避免布局跳动。
- 选中、禁用与错误的形态和色彩有一致规则。
- 焦点轮廓在粗边框之外仍可辨认，输入错误同时显示文字。
- 动效简短，拖动和移动结果清楚，不使用持续弹跳影响操作。

## 验收重点

边框粗细、阴影方向和配色语义统一。强视觉不会挤压表单空间或让所有元素都争抢注意力。
