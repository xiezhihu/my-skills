# 设置中心界面

## 适用与边界

适合以配置连接、模型、权限、账户和工作区为核心的工具。用于其他应用中的设置页时，只补充该页的配置工作流，不改变全局主题。

## 布局与视觉

- 左侧设置分类，右侧按任务分组的字段。表单较长且采用显式保存时，提供稳定的保存区域。
- 标签、必要说明、输入与错误信息层级清楚。不同组之间保留足够间距，不把所有字段挤成连续长表单。
- 布尔值使用开关或复选框，数值使用输入或步进器，固定选项使用菜单、单选或分段控件。
- 敏感值默认遮蔽，显示、复制和测试操作遵守产品实际能力。
- 视觉继承主方案，避免给每个设置行配一套装饰颜色。

## 关键交互

- 区分已保存、未保存、验证中、有效和无效，离开页面时按实际保存机制处理未保存更改。
- 显式保存与自动保存选一种清楚的机制，不让界面暗示已经保存而实际没有。
- 连接测试和保存分开，测试结果说明实际验证的范围，失败信息贴近相关字段。
- 更改连接参数后清除旧的测试结果，避免把旧成功状态用于新值。
- 敏感值不出现在日志、地址或错误提示中；复制后只显示简短状态。
- 重置或删除配置按影响提供合适的确认或撤销方式。

## 验收重点

用户能判断当前设置是否保存、哪些输入有问题，以及测试结果对应哪组值。键盘能够访问字段、错误与主要操作。
