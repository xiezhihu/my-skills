# 深色开发者界面

## 适用与边界

适合明确偏好深色的代码工具、项目管理器和开发者控制台。等宽字体用于代码、路径和日志；不把所有说明文字都改成等宽字体。只有日志输出的产品通常更适合终端与图形混合方案。

## 布局与视觉

- 按需要设置模块活动栏、项目文件树、编辑标签、主编辑区、底部输出及状态栏。
- 深色使用中性黑灰层次，避免所有面板混为一片。可参考背景 `#151515`、表面 `#202020`、正文 `#E5E7EB`。
- 蓝、绿等强调色只表示选中、操作或状态；错误、警告与成功维持一致语义。
- 正文参考 `13–15px`，代码参考 `12–14px`。文件树行高可在 `28–36px` 之间调整。
- 面板以分隔线和表面差异组织，不为每个面板添加厚阴影。

## 关键交互

- 文件树区分展开、选中、悬停、焦点与已修改状态。
- 编辑标签显示未保存状态，并提供关闭与键盘切换。
- 底部终端、问题和输出采用标签切换；错误数量可见。
- 状态栏呈现真实的全局状态和当前文件上下文，避免堆积无关信息。
- 命令面板、编辑区与终端之间的键盘焦点切换连续且可恢复。

## 验收重点

同时检查代码和普通文本对比度。切换文件、关闭标签、查看问题与恢复隐藏面板时，当前工作和未保存状态保持清楚。
